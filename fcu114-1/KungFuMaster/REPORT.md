### 4.5 角度計算方法

#### 4.5.1 六個關節角度定義

| 角度名稱 | 計算關鍵點 | 用途 |
|----------|------------|------|
| R_Elbow_Angle | 右肩(6) - 右肘(8) - 右腕(10) | 右手臂彎曲程度 |
| L_Elbow_Angle | 左肩(5) - 左肘(7) - 左腕(9) | 左手臂彎曲程度 |
| R_Knee_Angle | 右臀(12) - 右膝(14) - 右踝(16) | 右腿彎曲程度 |
| L_Knee_Angle | 左臀(11) - 左膝(13) - 左踝(15) | 左腿彎曲程度 |
| R_Hip_Angle | 右肩(6) - 右臀(12) - 右膝(14) | 右側身體傾斜 |
| L_Hip_Angle | 左肩(5) - 左臀(11) - 左膝(13) | 左側身體傾斜 |

#### 4.5.2 角度計算公式

```python
def calculate_angle(p1, p2, p3):
    """
    計算三點形成的角度
    p1, p2, p3: 三個關鍵點座標 (x, y)
    p2 為角的頂點
    """
    # 向量計算
    v1 = p1 - p2  # 從 p2 指向 p1 的向量
    v2 = p3 - p2  # 從 p2 指向 p3 的向量

    # 餘弦定理計算角度
    cos_angle = dot(v1, v2) / (norm(v1) * norm(v2))
    angle = arccos(clip(cos_angle, -1, 1))

    # 轉換為角度 (0-180°)
    return degrees(angle)
```

## 6. 挑戰與解法

### 6.1 挑戰一：站立姿勢誤判

**問題描述：**
當使用者站立不動時，分類器仍會輸出某個動作類別，導致誤判。

**解決方案：**
新增站立姿勢偵測機制：

```python
def is_standing_pose(angles, threshold=150):
    """
    檢查是否為站立姿勢
    當所有關節角度都接近 180° (直立) 時判定為站立
    """
    return all(angle > threshold for angle in angles)
```

**效果：**
- 成功過濾站立姿勢
- 減少 95% 的站立誤判

---

### 6.2 挑戰二：關鍵點遮擋問題

**問題描述：**
當身體部分被遮擋時（如手臂遮住身體、側身姿勢），YOLOv11 偵測到的關鍵點置信度會降低。

**解決方案：**
1. **使用置信度過濾**：只處理高置信度的偵測結果
2. **角度有效性檢查**：確保計算角度的三個點都被正確偵測

```python
def calculate_angle_safe(p1, p2, p3, conf1, conf2, conf3, threshold=0.5):
    if conf1 < threshold or conf2 < threshold or conf3 < threshold:
        return None  # 關鍵點不可靠，返回空值
    return calculate_angle(p1, p2, p3)
```

### 6.3 挑戰三：置信度不穩定

**問題描述：**
模型輸出的置信度在相鄰幀之間波動較大，導致顯示結果閃爍。

**解決方案：**
設定 85% 的置信度閾值，低於閾值時顯示 "Analyzing..."：

```python
if confidence < 0.85:
    display_text = "Analyzing..."
else:
    display_text = f"{action_name}: {confidence*100:.1f}%"
```

**效果：**
- 減少低置信度輸出
- 提升使用者體驗穩定性

### 6.4 挑戰四：動作重複計數

**問題描述：**
同一個動作在多幀中被重複計數，導致練習次數統計不準確。

**解決方案：**
追蹤上一個辨識的動作，只在動作變化時增加計數：

```python
class ActionPracticePage:
    def __init__(self):
        self.last_action = None
        self.action_count = 0

    def update_action(self, current_action):
        if current_action != self.last_action:
            self.action_count += 1
            self.last_action = current_action
```
